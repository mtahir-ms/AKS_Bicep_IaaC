# AKS BICEP Script

AKS Main Bicep file has parameters and AZ Deployment command to kick start the bicep deployment. It is very straight forward to create AKS Cluster with bicep scripts. You can run it in Bash or Powershell mode in Azure Shell or run in AZ CLI on your work machine or laptop. This particular scripts will create following 

AKS Cluster with 2 nodepools , System and User
It will have 3 Nodes on each nodepool 
You can expand on further settings as per your environment or requirements 
CNI Overlay networking
